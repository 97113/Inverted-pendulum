# ハードウェア構成

## 部品

| 役割 | 部品 | 備考 |
| --- | --- | --- |
| メイン制御 + 姿勢センサ | M5Stack Core2 | 内蔵 IMU (MPU6886 または BMI270) を使用 |
| CAN インタフェース + 電源 | M5Stack PwrCAN Module 13.2 | CA-IS3050G 絶縁トランシーバ、XT30(2+2) |
| 駆動 | RobStride EduLite 02 × 2 | CAN 1 Mbps / 29bit 拡張フレーム |
| 操縦 | Xbox Series X\|S コントローラ | BLE 接続 |
| 電源 | 18650 × 8 直列 | 24.0 V（空）〜 33.6 V（満充電）|

---

## ⚠️ 電源まわりの注意（最重要）

**PwrCAN Module 13.2 の電源入力は DC 9〜24 V です。18650 8 直列（満充電 33.6 V）を
そのままモジュールに入れるとモジュールが壊れます。**

XT30(2+2) コネクタは大ピンが電源、小ピンが CAN_H / CAN_L です。
モータとモジュールを XT30 ケーブルで素直にデイジーチェーンすると、
**バッテリ電圧がそのままモジュールの電源ピンに入ります**。ここが事故ポイントです。

### 推奨構成

```
                    ┌─────────────────────────────┐
  18650 ×8S ────────┤ 32V : モータ電源 (大ピン)      │
   (24〜33.6V)       │                             │
        │           │  EduLite 02 (左)  ──┐        │
        │           │  EduLite 02 (右)  ──┤ CAN_H  │
        │           └──────────────────┬──┴─CAN_L──┘
        │                              │
        └── DC-DC 降圧 (32V → 12V) ──┐  │
                                     │  │
                            ┌────────┴──┴──────────┐
                            │  PwrCAN Module 13.2  │
                            │   DC入力 12V         │
                            │   CAN_H / CAN_L      │
                            └──────────┬───────────┘
                                   絶縁 5V
                                       │
                                  M5Stack Core2
```

1. バッテリ 32 V はモータ 2 台にのみ直結する
2. **32 V → 12 V の DC-DC 降圧コンバータを 1 個挟み、その出力を PwrCAN の DC 入力
   （DC ジャックまたは HT3.96 / XT30 の電源ピン）に入れる**
3. Core2 は PwrCAN が供給する絶縁 5 V で動く（USB を挿しっぱなしにしなくてよい）
4. CAN_H / CAN_L は PwrCAN ⇄ モータ ⇄ モータ でデイジーチェーンする

DC-DC を省略したい場合は、モジュール側の XT30 の**電源ピンを結線せず**、
CAN_H / CAN_L の 2 線だけを繋ぎ、Core2 は USB か内蔵電池で動かします。
ただし PwrCAN の絶縁トランシーバ側の電源は DC 入力から作られているため、
この構成で CAN が動作するかはモジュールの版によります。まず DC-DC を入れる構成で
確認することを勧めます。

### 低電圧側の注意

EduLite 02 の最低動作電圧が 24 V の場合、18650 8 直列は放電末期（3.0 V/セル = 24 V）で
下限に触れます。**セルあたり 3.2 V（= 25.6 V）で使用を打ち切る**運用にしてください。
画面に表示される `VBUS` がモータの母線電圧です。

## CAN 配線とディップスイッチ

### GPIO の選択

PwrCAN 13.2 は M-BUS 上のどのピンを CAN_TX / CAN_RX に使うかをディップスイッチで選びます。
Core2 の M-BUS 割り当ては以下の通りです。

| M-BUS pin | 信号 | Core2 の GPIO | CAN 用途 | 可否 |
| --- | --- | --- | --- | --- |
| 2  | ADC    | **G35** | RX | ◎ 入力専用だが RX には問題なし |
| 14 | TXD0   | G1  | RX | ✕ USB シリアルと競合 |
| 16 | TXD2   | **G14** | TX | ◎ |
| 20 | PORT.A SCL | G33 | TX | △ PORT.A を使うなら不可 |
| 22 | GPIO   | G19 | RX | ○ |
| 24 | I2S_LRCK | G0 | TX | △ ブートストラップ端子のため非推奨 |
| 26 | I2S_DATA | G34 | RX | ○ 入力専用 |

本ファームウェアの既定値は **RX = pin 2 (G35) / TX = pin 16 (G14)** です。
別の位置にした場合は `include/config.h` の `kCanRxPin` / `kCanTxPin` を合わせてください。

### 終端抵抗

CAN バスは両端に 120 Ω が必要です。

- PwrCAN 13.2 側：ディップスイッチで 120 Ω を **ON**
- バスの反対側の末端（2 台目のモータ）：モータ側の終端を **ON**
- 中間のモータ：**OFF**

## モータの事前設定

RobStride の出荷時 CAN ID は **両方とも 127** です。このままでは 2 台を
同じバスに繋げません。RobStride の PC ツール（CAN-USB デバッガ経由）で
あらかじめ別々の ID を書き込んでください。

| モータ | CAN ID | `config.h` |
| --- | --- | --- |
| 左 | 1 | `kMotorIdLeft` |
| 右 | 2 | `kMotorIdRight` |

同時に以下も確認しておきます。

- ボーレートが **1 Mbps** になっていること
- 車輪を取り付けた状態で機械原点を設定しておく（本ファームでは相対角しか
  使わないため必須ではありません）

---

## 機体の組み立て

- Core2 は **画面が進行方向を向くように直立**させて取り付けるのが既定の前提です。
  別の向きに付けた場合は `config.h` の IMU 軸設定を直してください
  （DISARMED 画面に加速度・ジャイロの生値が出るので、それを見ながら決められます）。
- Core2 は回転中心（車輪軸）からなるべく離して、高い位置に置くほうが制御は楽になります。
- 左右のモータは向かい合わせに付くため回転方向が逆になります。
  `kMotorDirLeft` / `kMotorDirRight` で吸収してください。
- `config.h` の `kWheelRadius`（車輪半径）と `kTreadWidth`（左右車輪間距離）を実測値にします。

---

## 初回通電時のチェックリスト

車輪を浮かせた状態（台の上に乗せる等）で順に確認してください。

1. 電源を入れ、画面が `CALIBRATING` → `DISARMED` に進むこと
2. 画面右上の `CAN` が `OK` であること（`OFF` ならバス配線か終端を疑う）
3. 画面下段のモータ表示が両方 `ok` で、温度が表示されること
   （`--` のままなら CAN ID かボーレートの設定ミス）
4. `PAD` が `OK` になること（Xbox コントローラのペアリングボタンを長押しして待つ）
5. 機体を手で前後に傾けて、画面の角度表示が **前傾でプラス**になること
   （逆なら `kAccelPitchNumSign` と `kGyroPitchSign` を反転）
6. **車輪を浮かせたまま** ARM して、左スティックを前に倒したとき
   両輪が前進方向に回ること（逆なら `kMotorDirLeft` / `kMotorDirRight` の符号）

ここまで確認してから、初めて床に降ろしてください。
